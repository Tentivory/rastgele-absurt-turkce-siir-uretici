# Rastgele Absürt Türkçe Şiir Üretici

Bu proje, insanlığın en büyük sorunlarından biri olan "anlamsız şiir ihtiyacını" çözmek için yaratılmıştır.

## Nedir Bu?

Tamamen rastgele seçilmiş kelimelerden, anlamı olmayan ama kulağa şiir gibi gelen dizeler üreten devrim niteliğinde bir araç. Şairler yıllardır bunu manuel yapıyordu, biz otomatikleştirdik.

## Nasıl Çalışır?

```bash
python siir_uretici.py
```

Çalıştırdığınızda ekrana 4 satırlık absürt bir şiir basar. Tempo için hafif yavaşlama vardır, çünkü şiir aceleye gelmez.

## Özellikler

- %100 anlamsız
- %100 Türkçe
- %0 yapay zeka (şimdilik)
- Sonsuz kombinasyon
- Çay içerken okunabilir

## Uyarı

Bu şiirleri gerçek şiir sanıp sosyal medyada paylaşmayın. Yoksa insanlar sizi ciddiye alabilir.
